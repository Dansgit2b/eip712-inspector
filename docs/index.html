EIP-712 Inspector

Paste the JSON from an eth_signTypedData_v4 request and see what it actually authorises. It flags token Permits, Permit2 and Seaport/NFT listings, unlimited amounts, far-off deadlines and chain mismatches. It also computes the domain separator, struct hash and final digest, and recovers the signer when you add a signature. Everything runs in your browser.
